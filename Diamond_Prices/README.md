# Diamond Prices Analysis

This project explores a diamond prices dataset. The aim is to understand the data, check how its features are related to price and use charts to find patterns.

## What this project covers

- Loading and getting familiar with the dataset
- Checking data types, missing values and duplicates
- Exploring the distribution of important columns
- Comparing diamond features with price
- Creating visualisations and noting the main observations

## Tools

- Python
- Jupyter Notebook
- Pandas
- NumPy
- Matplotlib
- Seaborn

## Project files

- `Data/` – dataset files
- `Notebook/` – analysis notebook
- `Images/` – charts and saved visualisations

## What I practised

This project gave me practice with data cleaning, exploratory data analysis, visualisation and explaining patterns found in a dataset.

The observations and conclusions are documented in the notebook.
