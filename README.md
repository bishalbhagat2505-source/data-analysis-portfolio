# Data Analysis Portfolio

This repository contains my practice projects in data analysis and exploratory data analysis (EDA). I use these projects to practise working with datasets, cleaning data, visualising patterns and writing down useful observations.

## Projects

| Project | What I worked on |
|---|---|
| [Shoe Sales](./Shoe_Sales/) | Exploratory analysis of shoe sales, including sales patterns, brands and customer trends |
| [Student Performance](./student-performance/) | Exploring student performance data and looking for patterns in the dataset |
| [Diamond Prices](./Diamond_Prices/) | Working with diamond price data and exploring relationships between its features |

## Tools

- Python
- Jupyter Notebook
- Pandas and NumPy
- Matplotlib and Seaborn

## Repository structure

Each project has its own folder. Where applicable, the folder contains notebooks, data files, images and a project README.

## About

These are hands-on learning projects. I update them as I improve my data analysis, visualisation and communication skills.
